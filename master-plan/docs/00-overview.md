# 1. Project Overview

Futsal Tactical Analyst Lite adalah aplikasi web untuk membantu pelatih dan pemain futsal melakukan analisis pertandingan secara sederhana dan ringan. Aplikasi ini fokus pada pencatatan event pertandingan, visualisasi statistik, tactical board, upload video pertandingan, dan pembuatan laporan PDF.

Proyek ini dirancang agar:
- aman dijalankan di laptop Acer Nitro i5-11400H RTX 3050 RAM 16GB,
- tidak membutuhkan training AI besar,
- cocok untuk portfolio mahasiswa Teknik Informatika,
- dapat dikembangkan bertahap di masa depan.

---

# 2. Objectives

## Tujuan Utama
- Membuat aplikasi analisis pertandingan futsal berbasis web.
- Menyediakan statistik pertandingan otomatis.
- Menyediakan tactical board interaktif.
- Menyediakan laporan pertandingan dalam format PDF.
- Menunjukkan kemampuan full-stack development.

## Tujuan Portfolio
- Laravel API Development
- React Frontend Development
- Database Design (MySQL)
- Data Visualization
- File Upload Handling
- Software Architecture
- Git Workflow
- Documentation

---

# 3. Scope

## Included (MVP)
- Authentication (Coach & Player)
- Team management
- Player management
- Match management
- Match event input
- Automatic statistics
- Tactical board
- Video upload & playback
- PDF report export
- Responsive UI
- GitHub documentation

## Excluded (Future)
- Real-time collaboration
- Mobile native app
- Cloud deployment automation
- Multi-club management
- Advanced AI tactical analysis
- Player tracking AI training
- Live match tracking

---

# 4. User Roles

## Coach
- Create team
- Manage players
- Create match
- Upload video
- Input events
- Create tactics
- Download reports

## Player
- View team
- View matches
- View statistics
- View tactical board
- Download report (read-only)
