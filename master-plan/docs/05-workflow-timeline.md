# 11. Development Workflow

## Daily Workflow
1. Choose one small feature.
2. Write a specific AI prompt.
3. Generate code.
4. Run application.
5. Test feature.
6. Fix errors.
7. Commit to Git.
8. Update progress board.

## Git Commit Convention
```bash
feat: add match statistics API
fix: correct login validation
ui: improve dashboard layout
docs: update project plan
```
