- Tactical board works.
- PDF report can be downloaded.

# 20. Final Scope Decision

This project intentionally uses a **Lite architecture**:
- MySQL instead of PostgreSQL,
- no Docker,
- no cloud services,
- no heavy AI training,
- optional lightweight inference only.

This ensures the project remains stable, lightweight, beginner-friendly, and safe for the target laptop hardware while still providing a strong professional portfolio value.
